开源立场

oss

文派（广州）科技有限公司建立在开源技术之上。我们认可开源协议，并按协议原文履行义务。文风字体提供的源文件下载、网页字体服务与授权证明服务，同样建立在开源协议之上。

对于采用标准开源协议的字体，文派科技作为责任主体，可为合法合规使用的个人及企业出具《文风字体授权证明》，作为开源授权的证明材料。证明记录该字体在收录时的完整授权链、适用的开源协议、许可原文哈希，以及本站是否提供原件。证明不替代许可原文，也不为使用者创设新的权利。

其他品牌厂商自行发布的授权协议，本站只提供授权原文下载，文派科技不出具《文风字体授权证明》，也不代著作权人签署授权书。

SPDX text · chain + hash + original? · attest ≠ new rights · custom terms → text only

不卖字，不代言

no-sale

wenfeng.org 只做授权核对与源文件分发。本站不出售字体文件，不出售授权，不代理厂商收费或维权，也不代表任何著作权人授权。

no file sale · no license sale · no enforcement · no grant

出证范围

/legal#legal-scope

只给采用标准开源协议的字体出证；厂商自拟条款、许可还没核实的、未收录的不出证。完整清单见法务说明。收录与核验的方法写在我们怎么核。本站以前用 WordPress 做过，现已改为独立静态站点，与店面分开部署。

SPDX only · custom / unverified / unlisted → no attest · static · split deploy
