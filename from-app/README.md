# from-app · 从 fonts-front 复制的设计系统 + 对照实验室

**来源：** `Projects/fonts-front`（app.windfonts.com 店面）  
**用途：** 给 wenfeng.org 原型对照 / 谈设计，不是生产站。  
**入口：** `/from-app/lab.html`

本目录是一次性拷贝。路径已改成 `/from-app/...`，避免和 org 原型自己的 `/css/shop.css` 等撞车。

| 内容 | 路径 |
|---|---|
| 设计令牌 | `css/tokens.css` |
| UI 字体 | `css/fonts.css` + `assets/fonts/ui/` |
| 基础壳 | `css/base.css` `components.css` `site.css` |
| 对照索引 | `lab.html` + `data/lab-archive.json` + `docs/LAB.md` |
| 甲乙丙丁页 | `*-options.html` 及配套 css/js |

不要把这里的改动回写进 fonts-front，除非人明确要求。
