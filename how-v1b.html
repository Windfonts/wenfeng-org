许可怎么取证

evidence

以字体发布件内嵌的声明为准：安装包里的许可文件、官网许可页、上游仓库的 LICENSE，三者有其一才算拿到原文。

取证时记录来源、日期和文本哈希。哈希的作用是：原文以后被改动或换版时，能对出变化。

每款字体的取证记录，在它的许可原文页里可以查到。

embedded notice · package / page / LICENSE
source + date + hash
record on the license page

证明怎么签

attest

只给采用标准开源协议的字体出证，文派（广州）科技有限公司是出证责任主体。出证时申报用途（网页嵌入、印刷物料、软件内嵌、修改衍生、再分发），用途写入证明和台账，作为授权范围的确认记录。每份证明有唯一编号，签发即写入签发台账。

核对收到的证明：编号在台账查得到、内容与台账一致，才是文风签发的。编号对不上，按伪造处理。
