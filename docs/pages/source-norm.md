## 切片包命名（冻结）

`wenfeng-` 是访客识别文风的**唯一品牌前缀**，不可丢、不可改短成 `{norm}/`。

| | 形式 |
|---|---|
| zip | `wenfeng-{norm}.zip` |
| 解压目录 | `wenfeng-{norm}/` |
| 入口 | `fonts.css`（固定） |
| `{norm}` | 一律小写 slug，与 `f.norm` 一致；路径勿混用 `Xwwk` |

页内示例、`/use/`、客户端 zip 生成必须同名同大小写。
