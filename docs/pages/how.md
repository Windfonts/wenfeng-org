## 侧栏 · 五态

`_how_status_sidebar()`：`STATUS` 人话 + `_how_dual` 字段。

| 词 | 数据侧（摘要） |
|----|----------------|
| 本站下载 | `offer=source` |
| 官方下载 | `offer=jump`（含切片包在本页领取） |
| 暂无下载 | `offer=pending` · `textState=full` → `status=ready` |
| 待核实 | `offer=pending` · `textState≠full` |
| 未收录 | `offer=missing`；许可已核对仍可查原文；链报缺 |
