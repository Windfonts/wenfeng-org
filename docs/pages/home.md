状态：**定稿 D-09**。活页即此。对照 lab 可留，不改 `/`。

## 第一屏要回答的问题

这是什么站，我要办哪一件事，我要的字在不在？

1280×800 必须看见：页头、主门标题、检索、至少两条侧门。

## 骨架

```
wenfeng.org
开源商用字体（h1，玄宗体；「开源」更大，可编辑）
源文件按目录领取。许可允许再分发的在本站下载，其余到出处或领切片包。
[ 检索 ————————————— 搜索(墨) ]
本站下载 N 款 · 全部 N 款 →              01 授权查询 … N 份 →
                                         02 获取证书 … N 款 →
                                         03 缺字勘误 … 入口未接 →
```

左栏居中、满屏高、不铺灰底。模块顶边底边都有，左边不画竖线，上下沿线从右往左淡出。无四格统计条。无「关于本站」。无目录状态侧栏。无货架。

kicker `wenfeng.org` 用 `--fs-16`。

## 文案

人话两边都给。开发视图在旁追加字段，不替换主文案。

| 位置 | 常显 | 开发追加 |
|------|------|----------|
| kicker | wenfeng.org | （无） |
| h1 | 开源商用字体（可编辑活样张，仅设计） | `/source` |

## 禁止

样张条、pangram、关于段、01 墨黑整行、四格统计条、设计视图写「三态」、霞鹜文楷做主门标题。未得人点，不改骨架、大标题字体、侧门三事。不要把衬字改成常显，不要把正版 / 免费 / 造字换成法务近义词。
