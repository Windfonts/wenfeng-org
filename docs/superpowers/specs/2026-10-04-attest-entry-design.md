# `/attest/` 出证入口重设计

日期：2026-10-04  
状态：待实现  
范围：**仅** `/attest/` 活页外壳。不改证面、不改出证规则。

## 目标

首页「获取证书」点进来就能办事：选字体、填可选单位/用途、看清出证边界，一键生成证明。

## 已拍板

| 项 | 决定 |
|---|---|
| 范围 | A · 只做 `/attest/` |
| 第一屏主任务 | 直接出证（表单是主角） |
| 版式 | 甲 · 办事台 |
| 可出证列表 | **不要**（字体只在表单下拉） |
| 证面 `/attest/{norm}/` | 冻结（D-03） |
| 核对 / 台账 / `/v/` | 本轮不改版式 |

## 骨架

```
核验（kicker）
授权证明（玄宗 h1）
一句导语

┌─────────────────────┬──────────────┐
│ 出证表单              │ 出证边界     │
│ 字体（下拉，必填）     │ 谁签发       │
│ 持证单位 | 信用代码    │ 给谁出       │
│ 用途（五枚胶囊）       │ 不出         │
│ [生成授权证明]         │ 怎么核       │
│                       │ 出证范围 →   │
└─────────────────────┴──────────────┘

核验还能办的事（第二屏）
核对 JSON | 签发台账
证书查验  | 切片包
```

无面包屑装饰线堆砌。窄屏：边界移到表单下，左线改顶线。

## 表单与行为

- 字段与现网一致：字体 select、holder、uscc、usage 五勾选（网页嵌入默认开）。
- 提交：现有 `data-attest-form` → `/attest/go/` → `/attest/{norm}/`（含 query）。
- 不增字段；`can_attest` / SPDX 规则不动。

## 第二屏

- 四项办事：核对 JSON、签发台账、证书查验、切片包；两列清单行，不要营销大卡。
- **删除**「可出证的字体 · N 款」标题、`data-count`、以及 `index_rows` 可出证名单。

## 视觉约束（D-11 / DECISIONS）

- 大题玄宗，比首页小一档；沿用全站顶栏页脚。
- 站内 UI 不用红（公章除外）、无暖纸色、无投影堆叠、无渐变卖点墙。
- 用途用胶囊/勾选，气质对齐授权查询命中态的克制留白。

## 实现触点

- [`site/build.py`](../../site/build.py) · `page_attest_index`：拆第一屏 / 第二屏 markup；去掉列表。
- 新建 [`site/assets/pages/attest.css`](../../site/assets/pages/attest.css)（或等价 pages CSS），`pages_css("attest")` 挂上。
- [`docs/pages/attest.md`](../../pages/attest.md)：同步骨架（无列表）。
- `site.js`：出证跳转逻辑不改；若列表相关仅挂在本页，随 markup 删除即可。

## 验收

1. `/attest/` 第一屏可见大题、表单、边界；无需滚动即可点「生成」。
2. 页内无「可出证的字体」名单与检索列表。
3. 生成后仍进入对应 `/attest/{norm}/`，经典证面可用。
4. 四项办事链接可用；窄屏边界在表单下。
5. 16031 预览；不改 `/attest/{norm}/` 证面 HTML/CSS。
