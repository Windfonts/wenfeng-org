## 0. 为什么要先写这份方案

## 2. 首页要干的事（定位不改）

- wenfeng.org 做的是**源文件、许可原文、缺字反馈、授权证明**。不当店面，不当 CDN，不放样张墙（`HANDOFF.md` 必守条）。
- 首页 = **本站是什么 ＋ 进索引**。来访者大致三类：
  1. 看到嵌入注释、来查许可的开发者 → `/license/`
  2. 想拿源文件的设计师 → 检索 → `/source/{norm}/`
  3. 要授权证明的企业 → `/attest/`
- 所以首页只有一个**主动作：检索**。四件事是次级入口。数字只是信号，不单独占一块。

## 3. 设计约束（两版都要守）

- **Token**：只用 `site/assets/tokens.css` 里已有的变量，不新增颜色、字号、间距。白底、浅灰填充、胶囊、墨黑主按钮。无投影、无红色、无暖纸色（`HANDOFF.md`）。
- **网格**：两栏一律用全站 `.display / .split` 的 `1.2fr : 0.9fr`，列距 `var(--s-12)`。右栏左边缘（导语、侧栏竖线）整页只有一条对齐线。
- **左边缘**：所有块的文字左边缘都落在容器左线上（1280 宽时 x=24）。只有 hover 底色允许外扩，文字不外扩。
- **横线**：整页最多两条区块分隔线。
- **垂直节奏**（只用这三档）：
  - 区块之间 `--s-16`
  - 区块内的大组之间 `--s-10`
  - 组内 `--s-3` 到 `--s-6`
- **h1 字体**：默认用 UI 字体（普惠体 700），和其他页一致。玄宗体是 §7 的待拍项。
- **双视图**：每一处设计视图文案都要有开发视图对应（`.for-design / .for-dev`）。设计视图讲人话；开发视图只露路径、ID、字段、API。顶栏开关已撤，用 `?view=dev` 进入。
- **数据**：页面上的所有数字都由 `build.py` 计算，禁止写死常量。

### 5.1 第一步：两份整页稿（一个提交）

- 新建 `site/assets/home.css`，命名空间统一用 `.home-*`。只通过 `layout(..., extra_head='<link rel="stylesheet" href="/assets/home.css">')` 挂在首页和 lab 页上。
- `build.py` 新增两个函数 `page_home_a(data, fonts)` 和 `page_home_b(data, fonts)`，在 `main()` 里写到 `/lab/home-a/` 和 `/lab/home-b/`。活页 `/` 继续用现在的 `page_home`。
- 公共的计数抽成 `home_counts(data, fonts) -> dict`，两版共用。字段：`n, n_src, n_full, n_att, gen, recent[6]`。
  - `recent` 按 `lic(f)["verifiedAt"]` 倒序，同日期按 `norm` 排。
  - 镜像仓库数如果甲版要用，从 `data/export-report.json` 读，读不到就**不显示这一格**，不要退回常量。
- 复用现有 helper：`icon / link / aside / kv_rows / search / STATUS / spdx_of / wf`。列表行不要复用 `index_rows`（它是四列，带短码），写一个三列的 `home_recent_rows`。
- 提交信息：`feat(home-lab): 甲 丁′精修 / 乙 四栏 两份整页稿 [agent签名]`
- **交付给冯的就是两个 URL**：`/lab/home-a/`、`/lab/home-b/`。只发链接，不发截图（冯 10-03 明说过自己看）。

### 5.2 第二步：冯选定后精修（一个提交）

- 精修期间不许新增区块，不许换结构。要换结构就退回 5.1，重出整页稿。

### 5.3 第三步：接进活页（一个提交）

3. 删掉 hero 玄宗体的懒加载代码（`hero_face`、`data-face-norm`），除非 §7 拍板要保留。
4. 提交信息：`feat(home): 接入{甲|乙}′，删 hv4 旧样式 [agent签名]`
