名字

收录名、核验主名写成「文风·」加原名，例如文风·霞鹜文楷。这是平台命名，不是把字体改成文风的作品，也不转移商标。

字体文件内的版权声明、name 表、OFL 保留名（Reserved Font Name）仍用原名。派生件若以后出现，必须另起新名，不能带保留名。本核验只针对未改名的收录原件或切片包。

协议

spdx

只给标准开源协议出证。写在这一栏里的，才有《文风字体授权证明》。

  • SIL Open Font License 1.1
  • MIT

  • IPA Font License
  • CC0
  • CC BY / CC BY-SA（不含 NC）
  • M+
  • 带 Font Exception 的 GPL

CC 系授权的字体出证时，证明内保留作者署名，满足署名条款。

厂商自拟协议（如阿里巴巴普惠体授权协议）、仓耳字库免费开源字体授权声明、HarmonyOS / MiSans / OPPO 等厂商条款、只标「免费商用」而无正式协议文本的、许可还没核实的、未收录的。这类字如有授权原文，只提供下载。文派科技不出具证明，也不代著作权人签署授权书。是否可商用，以厂商原文为准。常见条款是免费商用、禁止再分发字体文件。

记录

record

这一栏记下：某日从某上游取得某款字、许可原文哈希、本站是否提供原件、可否按原文再分发。它填的是企业档案里「要一份盖章件」的缺口。

不等于软著登记，也不等于公证。本证不写软著号。

date · upstream · hash · original? · redist
archive gap · not 软著 · not notary · no registration number

三行

three lines

网页嵌入、安装到操作系统、把字体文件再分发给客户，三种行为边界不同。本证用三行结论分开写：网页嵌入、再分发原件、本平台是否提供原件。

字库文件（TTF / OTF / 源工程）在国内常被当作软件复制品。许可允许复制、修改、再分发时，按原文做；许可禁止再分发时，把文件拷进客户交付包就可能越权。本核验只记录平台读到的条款结论，不代替对交付包、安装包、App 内嵌的逐项审查。嵌入网页 CSS 与把原件放进安装程序，不是同一件事。

embed / redist original / site offers the file
TTF/OTF/source as software copies
CSS embed ≠ installer · no per-package review

读法

ofl

OFL 1.1：可以用于网站、印刷、软件内嵌（看原文）。可以修改、再分发，不得单独出售字体本身。保留名：未获作者书面允许，派生件不能用原名。本站切片包若只做技术子集、不改设计，仍标原名，包装可以写「文风切片包」。MIT 更宽。

use / modify / redist · no selling the font alone
RFN · slice may keep the original name · MIT wider

国内

cn

字体作为计算机软件，一般按软件作品保护。单字图形是不是美术作品，法院判决并不统一，采购时不要把「开源」理解成「字形不受保护」。

开源许可是著作权人允许他人使用的书面条款。企业使用 OFL / MIT 字体，通常不必再向作者另签一份「授权证明」，但采购、审计、客户验收仍常要归档材料。核验就是给这份材料。侵权投诉仍走著作权人。

software work · glyph-as-art is unsettled
OFL/MIT usually needs no extra grant · archive still wants paper
complaints go to the rightsholder

签名

sign

授权证明由平台密钥签名，贴到核对页即可验证内容是否被改过。它不是可靠电子签名，也不是 CA 签发的数字证书，只是平台的核验记录。

不要把它交给公证处当「已公证」。需要公证或电子认证时，另走法定程序。核验 JSON 可以作辅助证据：证明某日平台对某哈希、某 SPDX 做过签名。印迹是视觉签章产品，与本证无关，不要混用。

platform key · not a reliable e-sign · not a CA
JSON is auxiliary evidence of hash + SPDX on a date
印迹 is unrelated

档案

archive

  1. 保存本核验 PDF / 打印件和 JSON。
  2. 保存许可原文（本站 /license/{短码}）。
  3. 若拿走了原件，保存当时的归档包和哈希，复核时要用。
  4. 持证单位栏只表示这一份副本放在哪家单位的档案里，不等于被授权人。

PDF + JSON · license text · file hash if taken
holder ≠ licensee

带走

redist

许可允许再分发、本站也提供原件的（目录里标「本站下载」）：可以按原文带走原件。厂商不允许再分发的字体：本站不提供文件，也不出证。若你已从厂商取得原件，可在 /slice/{短码}/ 上传核验后领取自托管切片包。核验在浏览器内完成：体积只作预检，识别以整包摘要为准（生产对照本站收录的 SHA-256，厂商若公布 MD5 则并列）。本原型只模拟流程，不上传服务器，也不把原件再切一遍。

不要把 cn.windfonts.com 的 woff2 拷走当源文件。嵌入代码里的 https://wenfeng.org/license 不能改。OFL 禁止单独出售字体本身。厂商不允许再分发的字体，更不能卖文件。

offer=source → original · else no file / no attest
/slice after you hold the file · SHA-256 · no upload in this prototype
do not copy woff2 · do not edit the license URL · no selling the file

状态

status

许可尚未核对、或源文件还没进镜像的款，不出核验。不要把店面能预览当成可以安装、可以再分发。

钓鱼条款、个人免费、登录墙领取，一律按原文。拿不准就当不能带走。

unverified / unlisted → no attest
preview ≠ install ≠ redist
phish, personal-free, login wall → read the text

来信

mail

收录信息有误，或对某条目有权利主张，写信到 license@wenfeng.org，说明是哪一条、问题在哪（权利人请附权利证明）。

核实期间，该条目标为「待核实」，暂停出证，也不提供文件。确认有误就下架，变更记录留在目录状态里；文风下架以核验页和目录状态为准。被下架的一方有异议，同样来信说明；是否恢复，按最新核对结果处理。

license@wenfeng.org · rightsholder attaches proof
hold → 待核实, no attest, no file
status on the catalog · restore only after recheck
