先问

ask first

左边是你要问的，右边是回答。原件、切片、店面用字仍是三件不同的事，只是不并排、也不按先后四步。怎么核在另一页。

question | answer
not 3 cols · not 4 steps · not /how

  1. 要文件本身？

    want the file?

    拿原件。TTF / OTF / 上游仓库归档。给自建站、主题作者。许可允许时才再分发。

    ttf · otf · upstream archive
    redistribute only if allowed

  2. 要放进主题？

    into a theme?

    用切片包，给 WordPress 和静态站本地 @font-face。开源字体的切片包稍后提供。不允许再分发的免费商用字体：上传从厂商下载的原包 zip（不要解压），核验通过后领取。走切片工具。

    local @font-face
    oss slice later · no-redist zip → /slice

    解压后整个文件夹放进主题（或 wp-content/fonts）。包内 fonts.css 已写好 @font-face 和必须保留的注释，整只引入，不要拆。

    whole folder · fonts.css intact · do not split

    // functions.php 里排队引入
wp_enqueue_style(
  'wenfeng-slice-xwwk',
  get_theme_file_uri( '/fonts/wenfeng-slice-Xwwk/fonts.css' ),
  array(),
  null
);

/* 或在主题 style.css 顶部 */
@import url( "./fonts/wenfeng-slice-Xwwk/fonts.css" );

  3. 只在网页里用？

    cite, not save?

    用 cn.windfonts.com 托管的 CSS 和字体分片。这不是本站下载，不要拿去二次托管。

    cn.windfonts.com
    not a download · no rehost

    不要把 cn.windfonts.com 的 woff2 拷走当源文件。托管分片不是原件，也不是切片包。

    do not copy hosted woff2 · not the source file

  4. 这一行能删吗？

    drop the comment?

    不能。注释里的 https://wenfeng.org/license 要留着。不允许再分发的字体走切片工具。

    keep license comment · no-redist → /slice

    嵌入代码里这一行不能改

    comment · keep

    <!-- 本页嵌入的字体由文风字体（Windfonts）提供，可自由使用；请保留本授权标注 https://wenfeng.org/license -->

  5. 用程序查？

    query it?

    查目录 API。免费和商业都可以查。商业字只出字段，files 为空。不是店面的 /api/css。lineage 字段为造字平台预留，现在恒为 null。

    commercial → fields only, files []
    not shop /api/css · lineage = null

    • GET /api/v1/fonts全部条目
    • GET /api/v1/fonts?offer=source本站下载
    • GET /api/v1/fonts?q=霞鹜按名搜
    • GET /api/v1/fonts/Xwwk一款 · 有 files
    • GET /api/v1/fonts/Albbphtfiles 为空

    • GET /api/v1/certs/Xwwk一款核验 JSON
    • POST /api/v1/certs/verify核对本份签名
