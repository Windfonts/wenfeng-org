三种拿走

3 ways

原件、切片、店面用字不是同一件事。先选一路。放进主题、查目录，写在下面，不跟三路并排。怎么核在另一页。

file · slice · hosted css
theme + /api/v1 below · not /how

  1. 01

    原件

    archive

    TTF / OTF / 上游仓库归档。给自建站、主题作者。许可允许时才再分发。

    ttf · otf · upstream archive
    redistribute only if allowed

  2. 02

    切片包

    slice

    给 WordPress 和静态站本地 @font-face。开源字体的切片包稍后提供。不允许再分发的免费商用字体：上传从厂商下载的原包 zip（不要解压），核验通过后领取。

    local @font-face
    oss slice later · no-redist → /slice

  3. 03

    网页里用

    hosted

    cn.windfonts.com 托管 CSS 和字体分片。不是本站下载，不要拿去二次托管。

    cn.windfonts.com
    not a download · no rehost

不要把 cn.windfonts.com 的 woff2 拷走当源文件。注释里的 https://wenfeng.org/license 要留着。不允许再分发的字体走切片工具。

do not copy hosted woff2 · keep license comment · no-redist → /slice

嵌入代码里这一行不能改

comment · keep

<!-- 本页嵌入的字体由文风字体（Windfonts）提供，可自由使用；请保留本授权标注 https://wenfeng.org/license -->

切片包进主题

enqueue

解压后整个文件夹放进主题（或 wp-content/fonts）。包内 fonts.css 已写好 @font-face 和必须保留的注释，整只引入，不要拆。

whole folder · fonts.css intact · do not split

// functions.php 里排队引入
wp_enqueue_style(
  'wenfeng-slice-xwwk',
  get_theme_file_uri( '/fonts/wenfeng-slice-Xwwk/fonts.css' ),
  array(),
  null
);

/* 或在主题 style.css 顶部 */
@import url( "./fonts/wenfeng-slice-Xwwk/fonts.css" );

commercial → fields only, files []
