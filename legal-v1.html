开源立场

oss

文派（广州）科技有限公司建立在开源技术之上。我们认可开源协议，并按协议原文履行义务。文风字体提供的源文件下载、网页字体服务与授权证明服务，同样建立在开源协议之上。

对于采用标准开源协议的字体，证明是开源授权的证明材料，不是一份新的许可。其他品牌厂商自行发布的授权协议，本站只提供授权原文下载。

文派 stands on OSS and the text as written
download · webfont · attest all sit on the license
custom terms → text only

核验是什么

what

文风授权证明是文派科技提供的开源授权证明服务。它记录：某日从某上游取得某款字、许可原文哈希、本站是否提供原件、可否按原文再分发。它填的是企业档案里「要一份盖章件」的缺口。

它不是著作权人出具的授权书，不创造新的使用权，不等于软著登记或公证。

chain + hash + original? + redist
not a grant · not 软著 · not notary

签发主体

issuer

签发人：文派（广州）科技有限公司。证面品牌：文风。产品：wenfeng.org。

文派科技是文风的运营主体和出证责任主体，不是霞鹜、阿里巴巴、Adobe 等字体的著作权人。授权证明记录的是开源协议在收录时的状态，不是「文派授权你商用这款字」。

issuer 文派（广州）科技有限公司 · brand 文风
not the copyright holder · not 「文派授权你」

文风·命名

name

本站收录名、核验主名写成「文风·」加原名，例如文风·霞鹜文楷。这是平台命名，不是把字体改成文风的作品。

字体文件内的版权声明、name 表、OFL 保留名（Reserved Font Name）仍用原名。派生件若以后出现，必须另起新名，不能带保留名。本核验只针对未改名的收录原件或切片包。

catalog name ≠ derivative
RFN stays · attest covers unmodified original or slice

著作权法

copyright

字体作为计算机软件，一般按软件作品保护。单字图形是不是美术作品，法院判决并不统一，采购时不要把「开源」理解成「字形不受保护」。

开源许可是著作权人允许他人使用的书面条款。企业使用 OFL / MIT 字体，通常不必再向作者另签一份「授权证明」，但采购、审计、客户验收仍常要归档材料。核验就是给这份材料。

网页嵌入、安装到操作系统、把字体文件再分发给客户，三种行为边界不同。本证用三行结论分开写：网页嵌入、再分发原件、本平台是否提供原件。

侵权投诉仍走著作权人。本页不是法律意见，不能替代律师审查具体项目。

software work · glyph-as-art is unsettled
OFL/MIT usually needs no extra grant · archive still wants paper
embed / install / redist are three lines
complaints go to the rightsholder

软件保护条例

software

字库文件（TTF / OTF / 源工程）在国内常被当作软件复制品。许可允许复制、修改、再分发时，按原文做；许可禁止再分发时，把文件拷进客户交付包就可能越权。

本核验只记录平台读到的条款结论，不代替对交付包、安装包、App 内嵌的逐项审查。嵌入网页 CSS 与把原件放进安装程序，不是同一件事。

TTF/OTF/source as software copies
no redist → do not ship the file
CSS embed ≠ installer

OFL 要点

ofl

可以用于网站、印刷、软件内嵌（看原文）。可以修改、再分发（不得单独出售字体本身）。保留名：未获作者书面允许，派生件不能用原名。本站切片包若只做技术子集、不改设计，仍标原名，包装可以写「文风切片包」。

MIT 更宽。厂商协议的读法见上面的「不出证」：只提供授权原文，不出具证明。

use ok · modify + redist ok · no selling the font alone
RFN · slice may keep the original name
MIT wider · custom terms → no attest

电子签名

sign

授权证明由平台密钥签名，贴到核对页即可验证内容是否被改过。它不是可靠电子签名，也不是 CA 签发的数字证书，只是平台的核验记录。

不要把它交给公证处当「已公证」。需要公证或电子认证时，另走法定程序。核验 JSON 可以作辅助证据：证明某日平台对某哈希、某 SPDX 做过签名。

platform key · not a reliable e-sign · not a CA
JSON is auxiliary evidence of hash + SPDX on a date

企业采购

archive

  1. 保存本核验 PDF / 打印件和 JSON。
  2. 保存许可原文（本站 /license/{短码}）。
  3. 若拿走了原件，保存当时的归档包和哈希，复核时要用。
  4. 持证单位栏只表示这一份副本放在哪家单位的档案里，不等于被授权人。

PDF + JSON · license text · file hash if taken
holder ≠ licensee

再分发

redist

许可允许再分发、本站也提供原件的（目录里标「本站下载」）：可以按原文带走原件。厂商不允许再分发的字体：本站不提供文件，也不出证。若你已从厂商取得原件，可在 /slice/{短码}/ 上传核验后领取自托管切片包。核验在浏览器内完成：体积只作预检，识别以整包摘要为准（生产对照本站收录的 SHA-256，厂商若公布 MD5 则并列）。本原型只模拟流程，不上传服务器，也不把原件再切一遍。

不要把 cn.windfonts.com 的 woff2 拷走当源文件。嵌入代码里的 https://wenfeng.org/license 不能改。

offer=source → take the original
no redist → no file, no attest · /slice after you hold the file
browser hash · SHA-256 · prototype does not upload
do not copy woff2 · do not edit the license URL

待核实

unverified

许可尚未核对、或源文件还没进镜像的款，不出核验。不要把店面能预览当成可以安装、可以再分发。

钓鱼条款、个人免费、登录墙领取，一律按原文。拿不准就当不能带走。

unverified / unlisted → no attest
preview ≠ install ≠ redist
phish, personal-free, login wall → read the text

下架与异议

takedown

收录信息有误，或对某条目有权利主张，写信到 license@wenfeng.org，说明是哪一条、问题在哪（权利人请附权利证明）。

核实期间，该条目标为「待核实」，暂停出证，也不提供文件。确认有误就下架，变更记录留在目录状态里；文风下架以核验页和目录状态为准。被下架的一方有异议，同样来信说明；是否恢复，按最新核对结果处理。

license@wenfeng.org · rightsholder attaches proof
hold → 待核实, no attest, no file
status on the catalog · restore only after recheck

常见误读

misread

  • 「文派把著作权转给你」：没有这种授权。文派出具的是开源授权证明，标题是《文风字体授权证明》。权利仍以许可原文为准。
  • 「厂商协议也能盖文派的章」：不能。标准开源协议才出证；厂商自拟协议只提供原文下载。
  • 「被授权人」：持证单位只表示这份副本放在哪家单位档案里。
  • 「软著号 / 商标转让」：本证不写。文风· 是收录名，不是把原字体改成文风的作品，也不转移商标。
  • 「盖了章就能卖字体文件」：OFL 禁止单独出售字体本身；厂商不允许再分发的字体更不能卖文件。
  • 「印迹印章」：视觉签章产品与本证无关，不要混用。

no assignment · no foundry stamp · holder ≠ licensee
no 软著 / no trademark · no selling the file · 印迹 is unrelated
